## Projects

### I-Poten — AI 모의면접 플랫폼 `운영 중`
**3인 팀 · 백엔드/인프라 리드 · 2025.10 ~ 운영 중 · MAU 600+**
Java 17 · Spring Boot 3.5 · FastAPI · MySQL · Redis · Docker · Nginx · AWS EC2

- 인증을 Interceptor + 커스텀 어노테이션 + ArgumentResolver 파이프라인으로 일원화 — 컨트롤러 인증 로직 71곳 → 0곳, 상태 조회 평균 2ms
- HttpOnly 쿠키를 Nginx가 읽을 수 있다는 점을 활용해 토큰 검증 트래픽 90%를 백엔드 도달 전 차단 (~200ms → 1ms 미만)
- RAM 3.7GiB 단일 EC2의 OOM을 진단·해결 — JVM 힙 미설정(compose `command`가 `ENTRYPOINT`를 덮어쓴 것이 근본 원인)을 찾아 피크 900~1200MiB → 600MiB, 프론트 빌드를 GitHub Actions로 이관해 배포 순간 메모리 6.4GiB+ → 2.9GiB 이내
- 면접 세션 1회당 OpenAI 비용을 토큰 단위로 실측($0.0864/회, 평가 단계가 87%) — 크레딧 과금 정책의 근거 수립, 호출 병합 시 40%+ 절감 로드맵 도출
- 면접 유형 분기를 Strategy 패턴 + Map 주입 디스패치로 구성 — 분기문 수정 없이 클래스 추가만으로 확장, 순환 참조는 `@Lazy` + Repository 직접 의존으로 해소
- 전사 보안 감사로 CRITICAL 3건 도출·전량 조치 — OpenAI 키 이미지 번들링 차단, 내부 API를 Nginx 403 + `X-Internal-Key`(fail-closed) 이중 방어
- AI 추론을 FastAPI로 분리하고 Spring은 오케스트레이션만 담당 — AI 대기가 일반 API를 지연시키는 문제 제거
- PM 부재 환경에서 백로그 500여 건 관리·스프린트 플래닝 주도
