# 자소서 소재 뱅크 — 문항 유형별 재조립용 문단

> 원리: 합격자 다수는 코어 스토리 2~3개를 회사별로 재배열할 뿐이다 (아카이브 151건 분석 결론).
> 사용법: 문항 유형에 맞는 문단을 골라 붙이고, 회사 리서치 문장만 새로 쓴다.
> 문체는 A·B·C 자소서와 동일 기준 — 두괄식, 소제목, 담백한 단정문, 결의형 최소화.
> ⚠ 같은 서류 안에서 한 소재를 두 문항에 쓰지 않는다 (창해에탄올 docx의 실수 — 2인팀 이야기가 3개 문항에 반복됨).

---

## 1. 지원동기 진입로 3종 (틀)

**① 사업구조 → 필연 → 나** (가장 강력, 리서치 필요)
> ○○의 [사업 특성]은 [구조적 요구]를 전제합니다. 이런 환경에서는 [역량]이 필연적으로 요구됩니다. 제가 [실무/프로젝트]에서 해 온 일이 정확히 그 지점에 닿아 있습니다.

**② 한계 고백** (성과 먼저, 병목 나중 — 성과 없이 쓰면 자기 격하가 됨)
> 세 명이 MAU 600 규모 서비스를 운영하며 인증·배포·모니터링을 직접 다뤘습니다. 그러나 사용자가 수만을 넘을 때 필요한 판단은 아직 경험하지 못했습니다. 그 판단을 ○○의 [규모/도메인]에서 배우고, 제가 훈련해 온 [무기]로 기여하고 싶습니다.

**③ 직무 재정의** (직무이해 문항 겸용)
> [직무]는 [통념]이 아니라 [재정의]라고 생각합니다. — 예: "공정 IT 개발은 설비를 다루는 일이 아니라 현장 데이터를 판단 가능한 형태로 바꾸는 일입니다." / "은행 IT는 지원 부서가 아니라 상품 그 자체입니다."

## 2. 문제해결 소재 (문항당 1개만 사용)

**[A] OOM 오진 교정** — 대표 소재. 자소서 A-2 참고. 키워드: 발생 지점 ≠ 원인 지점, 0=무제한, 회귀 커밋, 버퍼 100건 보장
**[B] 300GB 무스캔 진단** — 데이터·DBA·금융 계열에 최적. 자소서 B-3 참고. 키워드: 운영 DB 제약, 메타데이터 판정, 재발 감시 화면
**[C] 커넥션 풀 수요 계산** — 설계 역량 문항에 최적. 키워드: 공급 N vs 수요 2N+2, 총량 72, 자체 재검토로 결함 추가 발견
**[D] EC2 메모리 생존기** — 인프라·DevOps 계열. 키워드: ENTRYPOINT 덮어쓰기 발견, 빌드 이관, 6.4GiB→2.9GiB
**[E] 2인 팀 최종 프로젝트** — 신입 공채·협업 문항 겸용. 키워드: 범위 재설계, 역할 재배치, 과정 최초 2인 팀 수상

## 3. 협업·갈등 소재

**[F] 근거 세미나 문화** — "새 기술을 소개하는 자리가 아니라 왜 써야 하는지 따지는 자리. 근거가 부족하면 그날은 도입하지 않습니다."
**[G] 설계를 스스로 되돌림** — 기술 우위보다 제품 일관성. 되돌린 설계를 복원 가능한 문서로 백업. (성숙함 어필, 시니어 면접관에게 강함)
**[H] 표로 만든 합의** — 의견이 갈리면 남은 기간과 작업량을 표로 정리해 공유. "무엇을 덜어낼지가 감정이 아니라 숫자의 문제가 됐습니다."
**[I] 팀/개인 경계 자진 신고** — AsianMart 커머스 기반은 팀, 구매관리 6도메인은 개인 확장. (신뢰 장치 — 물어보기 전에 먼저 말함)

## 4. 실패·좌절 소재

**[J] WHERE 없는 UPDATE 사고** — 운영 DB 사고 → 즉시 원복 → 이후 모든 SQL 멱등+롤백 표준화. "실수는 절차로 막는다."
**[K] 폴백 코드 자체 결함** — 배포 직후 "정확히 1건" 증상에서 내 코드의 버그를 역추적. "방금 고친 코드가 다음 버그의 1순위 용의자."
**[L] 컨디션 붕괴** — 무리한 몰입 → 성과 하락 → 운동·수면을 일정처럼 관리. (인성 문항용, 직무 비치명적 단점)

## 5. 자기주도·학습 소재

**[M] 편입** — 학원 없이 자기주도로, 등록금 자립. 낯선 커리큘럼 → 3.81 졸업 + 최우수 프로젝트
**[N] 블로그 16편 + 작성 명세** — 글을 쓰는 것을 넘어 팀의 글쓰기 규격을 문서화. "누가 쓰든 같은 구조가 나오게"
**[O] 레거시 복원** — 아무도 못 돌리던 Java 7 + Ant + Oracle 3층 구조를 규명해 실기동. (전통기업·SI에 강함)

## 6. AI 활용 소재 (2026 트렌드 문항)

**[P] AI 업무 미들웨어** — 자연어 요청으로 반복 작업을 수행하는 도구를 지시 없이 만들어 팀이 사용 중
**[Q] AI 비용 실측** — 면접 1회 $0.0864(≈121원), 평가 단계 87% 규명 → 과금 정책 근거. "AI를 쓰는 것과 AI의 비용 구조를 아는 것은 다른 역량입니다."
**[R] 검증 게이트** — AI와 페어로 구현하되 산출물은 문서·검증 기준으로 통제. 논의와 결정을 기록해 자산화 (I-Fence Engineering Memory)

## 7. 마무리 문장 (결의형 대체)

- "그 자리에서 쓰이고 싶습니다."
- "오래 남아 ○○ 시스템을 가장 잘 아는 사람이 되겠습니다."
- "입사 후 3개월 안에 [도메인]을 파악하고, 이후 [구체 영역]에서 결과로 기여하겠습니다."
- (금지: "최고의", "성장하겠습니다", "부족하지만", 처우·복지 언급)

## 문항 유형 → 소재 매핑표

| 문항 유형 | 1순위 | 2순위 | 비고 |
|---|---|---|---|
| 지원동기 | 진입로 ①~③ + 리서치 | — | 회사 고유명사 필수 |
| 문제해결/도전 | A | B, C | 테크=A, 데이터·금융=B, 설계=C |
| 협업/갈등 | G 또는 H | F, E | 신입 공채는 E |
| 실패/좌절 | J | L | 인성 중심이면 L |
| 성장과정 | M | — | 블라인드 주의 |
| 자기주도학습 | N | O, M | |
| AI/디지털 역량 | Q | P, R | |
| 성격 장단점 | 장점=B의 신중함 / 단점=L | | 단점에 게으름·지각류 금지 |
| 입사 후 포부 | 3개월 지도 → 기여 영역 → 리스크 관리 문장 | | 연차별 로드맵 요구 시 1년/5년 분리 |
